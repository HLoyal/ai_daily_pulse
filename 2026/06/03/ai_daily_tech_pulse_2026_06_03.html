Benchmarks 极致性能进化

SOTA Normalization 突破：torch.compile 自动算子融合实现对 Eager 17倍提速

PyTorch 团队发布了关于 Normalization（如 LayerNorm, RMSNorm）编译优化的最新基准测试。借助全新的 MixOrderReduction 编译器融合后端，torch.compile 无需任何手动手写优化代码，即可展现出超越手写算子库（如 Liger 和 Quack）的极致端到端性能。

⚡ 基准表现： 开启 MixOrderReduction 后，编译运行比常规 Eager 模式提速 17.07倍，对比目前业界先进的 Liger 提速了 1.45倍，充分展示了自动算子融合在逐元素与高维 Reduction 混合运算中的巨大威力。

torch.compile 代码实践

PyTorch 2.12+

基于 PyTorch Europe 2026 发布的无 Graphbreak 编译模型，如何在代码层融合自定义算子：

custom_ops_compile.py 
import torch
import torch._custom_ops as custom_ops

# 注册一个自定义 CUDA 算子而不会引发 Graphbreak
@custom_ops.register_custom_op("my_ops::rms_norm_fused")
def rms_norm_fused(x: torch.Tensor, weight: torch.Tensor) -> torch.Tensor:
    ... # 绑定你的高性能 Triton/Helion Kernel

class ModernLLM(torch.nn.Module):
    def __init__(self, d_model):
        super().__init__()
        self.weight = torch.nn.Parameter(torch.ones(d_model))
        
    def forward(self, x):
        # 编译器会连同后续的 Linear 自动融合为一个整体 Kernel
        out = torch.ops.my_ops.rms_norm_fused(x, self.weight)
        return torch.relu(out)

# 启用优化并保留完整的自定义图捕获能力
model = torch.compile(
    ModernLLM(4096).cuda(), 
    options={"mix_order_reduction": True} # 启用最新 SOTA 融合引擎
)
